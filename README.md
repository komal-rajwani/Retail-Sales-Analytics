# Retail Sales Analytics & Predictive Modelling

## Project Overview
An end-to-end Retail Sales Analytics project focused on analyzing sales performance, customer behaviour, product demand, inventory, and business trends.

The project integrates Snowflake, Databricks, Python, Power BI, Machine Learning, and Streamlit to transform retail data into actionable business insights.

## Tools & Technologies
- **Snowflake:** SQL-based data storage and analytical queries
- **Databricks:** Data processing and analysis
- **Python:** Pandas, NumPy, Scikit-learn
- **Power BI:** Interactive business intelligence dashboards
- **Machine Learning:** Linear Regression and Random Forest
- **Streamlit:** Interactive analytics and prediction application

## Business Objectives
- Analyze overall retail sales and revenue performance
- Identify product and customer purchasing trends
- Evaluate sales performance across stores and channels
- Explore inventory and promotional performance
- Develop and evaluate predictive models for transaction-level sales quantity
- Present business insights through dashboards and an interactive application

## Dataset
Analyzed approximately 641,000 retail sales records, alongside related business data covering products, customers, stores, inventory, and promotions.

## Project Workflow

### 1. Data Preparation & SQL Analysis
Used Snowflake and SQL to work with retail datasets, perform analytical queries, and investigate business KPIs.

### 2. Data Processing
Used Databricks and Python for data preparation, exploratory analysis, and modelling workflows.

### 3. Power BI Dashboard
Developed interactive dashboards to visualize:
- Sales trends and performance
- Product and category performance
- Customer segments
- Store and channel performance
- Inventory and promotional insights

### 4. Predictive Modelling
Developed and compared:
- Linear Regression
- Random Forest Regression

**Prediction Target:** Transaction-level quantity sold.

**Evaluation Metrics:** Mean Absolute Error (MAE) and R² score.

The models were assessed for predictive performance and limitations. Results illustrate the challenges of predicting transaction quantities using the available features.

### 5. Streamlit Application
Developed a Streamlit application for interactive KPI exploration, data visualization, and model testing.
